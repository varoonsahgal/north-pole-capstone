The elf code

Four teams share one AWS account. These five rules keep everyone's work safe.

RuleWhy it matters
Your team name goes first. Everything you create starts with it, for example [[TEAM]]-cluster.Names must be unique inside one account. A prefix also tells you at a glance what is yours.
Stay in Oregon. Use the us-west-2 region for everything.Resources in another region are invisible to your teammates and easy to forget (and keep paying for).
Touch only your own toys. Never edit or delete a resource that carries another team's name.Everyone here has administrator rights. That is a lot of trust.
No keys in code. Never paste an AWS access key into a file or into GitHub.Bots find leaked keys on GitHub within minutes. Your workshop already has safe, temporary credentials built in.
Leave no trace. When a mission ends, run the cleanup.Load balancers and clusters cost money every hour they exist.
